# Archai Showcase — visual, motion, performance and SEO review

Date: 2026-10-13

## Changes implemented

### Hero and atmosphere
- Replaced the previous homepage hero object with an original procedural planet: equirectangular surface texture, subtle topographic details, separate translucent cloud shell, Fresnel-style atmospheric rim, two restrained orbit rings and a small orbiting moon.
- Removed the heavyweight hero post-processing composer. The scene uses bounded DPR, moderate sphere detail and limited lights to avoid unnecessary GPU cost.
- Reworked the shared star/meteor Canvas with varied star size/tint/brightness, slow drift, selective diffraction glints and meteors with tapered gradient trails, varied speeds/angles, glowing heads and hot cores. It pauses for hidden tabs and respects reduced-motion preferences.

### Scene lifecycle and route transitions
- Kept `useFrame` hooks inside React Three Fiber components rendered under `<Canvas>`; the shared ready signal is emitted only after the scene's children have mounted and its first R3F frame has run.
- Added a stable procedural loading illustration behind each WebGL canvas, so delayed or failed WebGL does not leave a blank rectangle.
- Route changes now mount the destination beneath a brief opacity-only curtain before the curtain is revealed. The curtain listens for the current route's first visible scene frame, with a safety timeout for routes without a scene or when WebGL fails. The timeout is a fallback—not a claim that every below-the-fold WebGL scene has finished loading. Those scenes remain lazy to protect initial performance.
- Uses an isomorphic layout effect for the route curtain to avoid a one-frame flash on client navigation without introducing server-side `useLayoutEffect` warnings.
- Rebuilt GSAP/ScrollTrigger effects per pathname while keeping Lenis lifecycle separate, so triggers do not remain bound to elements from the previous route.
- Added Lenis' recommended CSS behavior to stop native `scroll-behavior: smooth` from competing with Lenis and preserve browser-native scrolling on touch and reduced-motion setups.
- Keeps reduced-motion behavior and fallbacks explicit.

### Page content and SEO
- Expanded the homepage in Arabic and English with service/capability summaries, engineering principles, delivery steps and clear service/contact calls to action. The new copy avoids unsupported customer counts or success percentages.
- Maintained a topic-specific scene map across the 12 locale page routes and their supporting page sections.
- Made the default Open Graph image fallback explicit for routes without a dedicated image; filtered invalid/blank image entries; kept document titles aligned with the locale layout's title template to avoid duplicate brand suffixes.
- Removed the non-functional `SearchAction` pointing to a non-existent search route, and only emits verified `http(s)` social URLs in Organization JSON-LD.
- Removed the hardcoded unverified Twitter creator handle. Footer social icons only appear when valid configured URLs exist; contact email only appears when configured and valid, otherwise the footer points to the contact form rather than a made-up address.
- Removed always-current sitemap `lastModified` values where the actual source modified time was not available. Reviewed localized canonical/hreflang generation and existing robots/sitemap route files.
- Made the new homepage content cards and CTA surfaces theme-aware for dark and light themes.

## Not verified in this environment

`node_modules` is absent and the package registry was unreachable from this environment (the offline npm cache also does not contain all locked packages). For that reason, a full dependency-backed typecheck, Next.js production build, browser smoke test, GPU frame-time profile and Lighthouse run are **not claimed as passed**. Syntax/import scans do not replace those tests, and static checks cannot confirm the live Supabase content or deployed metadata responses.
