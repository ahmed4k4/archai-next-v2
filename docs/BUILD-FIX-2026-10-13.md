# Build Fix & Static Review — 2026-10-13

## Error reported

`next/dynamic options must be an object literal` from `src/components/visuals/DynamicVisual.tsx`.

## Fix applied

- Replaced the shared `sceneOptions` variable with a direct options object at all 10 `dynamic()` call sites. Each call retains `ssr: false` and `loading: SceneChunkFallback`, keeping each 3D scene in its own chunk.
- Typed the scene registry with `satisfies Record<string, ComponentType<{ className?: string }>>`, which preserves the exact union of registered scene names in `VisualName`.
- Improved `safeUrl()` in `src/lib/i18n.ts`: invalid or non-HTTP(S) project URLs now return `undefined` instead of `#`. Project-card, slider and project-detail links only render when the URL is valid, so invalid database values cannot generate dead hash links.

## What was not verified

The local app should be checked on a machine with working registry access using:
