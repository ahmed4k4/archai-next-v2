# Visual redesign V3

## Direction
- Removed the homepage animated grid floor and the line-stream data animation that created visual noise.
- Rebuilt the homepage hero sculpture around a restrained central 3D core and layered dashboard panels, with slow low-amplitude motion.
- Replaced the home backdrop's 18 moving strands with a small number of quiet floating interface tiles and beveled objects.
- Removed the moving grid from marketing-page hero sections and the ambient CSS grid field.
- Kept per-page WebGL backdrop scenes mapped to each topic (services, industries, about, process, insights, contact, case studies, careers, FAQ, projects/categories).
- Reduced ambient backdrop contrast and rotation speed; made content cards read as layered product surfaces with subtle perspective depth.
- Kept responsive and reduced-motion behavior.

## Validation note
Static source edits only. Run `npm install`, `npm run typecheck`, and `npm run build` in the project environment before deployment.
