# Archai Showcase — Review / Implementation Handoff

**Revision date:** 2026-10-13  
**Scope:** Public-facing motion system, deferred 3D, SEO metadata, accessibility fallbacks, documentation, and static validation.

## Changes applied

- Added GSAP + ScrollTrigger and Lenis as explicit dependencies and recorded them in the npm lockfile.
- Hardened `SmoothMotion`: desktop-only Lenis now uses its own RAF (`autoRaf: true`) instead of depending on GSAP ticker callbacks; ScrollTrigger syncs on Lenis scroll events. Cleanup removes stale Lenis state classes, and small/touch screens and reduced-motion preferences keep native scrolling.
- Added `LazyVisual`, which creates a 3D scene when near the viewport, keeps a consistent CSS placeholder before mount, and avoids initializing all lower-page WebGL scenes during initial paint.
- Reduced procedural particle counts, capped Three.js pixel ratios, disabled expensive supporting backdrop post-processing on small/reduced-motion layouts, and selected the low-power GPU preference for non-hero scenes. The shared galaxy background remains a single 2D canvas; star density is high while meteor streaks are thinner, softer and limited to two at once. `Scene3D` pauses the render loop when a visual leaves the viewport, resuming it when the user returns.
- Added a lightweight SpotlightCard-style hover treatment to marketing service cards without a new runtime dependency.
- Added 3D hero compositions to project/category detail pages and supported RTL placement for their visual layers.
- Fixed the reported R3F context error by keeping `HeroCoreScene` and its `useFrame` callback inside the `Scene3D`/`Canvas` tree. The hero also resolves its staged reveal immediately when reduced motion is requested, preventing an invisible frozen model.
- Replaced the legacy home backdrop’s 42 rising data streams with a central metallic core and two restrained orbital rings so old imports cannot restore the falling-line effect.
- Fixed the public page wrapper so layouts do not wrap each page's own `<main>` in another `<main>` landmark.
- Added explicit localized home metadata and localized Open Graph/Twitter title suffixes. Updated unsupported portfolio statistics to capability facts instead of unverified client/project/satisfaction claims.
- Removed hard-coded default admin email/password from the login form so the page no longer pre-populates reusable-looking credentials.
- Added `AGENTS.md`, `docs/design-system/MASTER.md`, `docs/ANIMATION-SYSTEM.md`, and requested skill install status documentation.
