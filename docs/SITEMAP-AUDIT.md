# Sitemap and indexable page inventory

The live XML URL supplied for review (`https://archai-website-navy.vercel.app/sitemap.xml`) returned XML that the available browser reader could not parse. Therefore this file records the sitemap generated by the current Next.js source, not a claim that the deployed XML was independently downloaded and audited.

## Static indexable routes (Arabic and English)

- `/ar` and `/en` — home
- `/{lang}/services`
- `/{lang}/industries`
- `/{lang}/about`
- `/{lang}/process`
- `/{lang}/insights`
- `/{lang}/case-studies`
- `/{lang}/careers`
- `/{lang}/faq`
- `/{lang}/contact`

## Dynamic indexable routes

- `/{lang}/categories/{slug}` — active categories returned by the public content query
- `/{lang}/projects/{id}` — public projects returned by the public content query

Every listed page receives Arabic/English alternate URLs and an `x-default` alternate in `src/app/sitemap.ts`.

## Intentionally excluded

- `/{lang}/search` — marked `noindex` to avoid indexing query-driven thin/duplicate result pages.
- `/admin/*` and `/api/*` — disallowed by `src/app/robots.ts`; admin responses also receive `X-Robots-Tag: noindex, nofollow`.

## Production checklist

1. Set `NEXT_PUBLIC_SITE_URL` to the canonical production origin before deployment.
2. Check the deployed `/sitemap.xml` and `/robots.txt` after deployment.
3. Submit the sitemap in Google Search Console and Bing Webmaster Tools.
4. Inspect a sample of project/category URLs to confirm that they return 200, have useful language-specific content, and do not contain placeholder titles or empty descriptions.
