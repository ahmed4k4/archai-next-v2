# Archai project/build fixes — 14 October 2026

## Fixed from the supplied Windows output

1. `src/components/HomeOverview.tsx`
   - Replaced language-literal inference with a shared `OverviewContent` type for Arabic and English.
   - Validated CMS text overrides as strings and array items against the expected fields before rendering. Invalid CMS structures fall back to the page's localized source copy.
   - This addresses the five reported TypeScript errors on `capabilities`, `audiences`, `principles`, `process`, and `questions`.

2. `scripts/verify-source.mjs`
   - Dependency specs are now compared by key/value, independent of JSON property order. The previous check could fail even when `package.json` and the lockfile contained the same dependency specs.

3. `src/components/visuals/HeroCore.tsx`
   - Added a controlled, subtle system float and gentle orbit motion; increased the visible rotation rate while keeping the compact planet composition and mobile DPR limits.

4. Existing project-page and performance safeguards remain in place:
   - Supabase requests have a bounded timeout; public project records remain database-driven.
   - CMS read failures fall back to localized source copy.
   - The route curtain has a hard upper time bound and does not wait for every off-screen WebGL scene.
   - Lower-page visuals mount progressively; project links disable automatic prefetch to reduce unnecessary requests.

## Applying safely

- Keep your existing `.env.local`; it is intentionally not included in the archive.
- Extract the full ZIP over a copy of the project, or apply `archai-hotfix-files.zip` to the existing project to replace only the three changed source/script files.
- From the project directory run `npm run verify:source`, `npm run typecheck`, and `npm run build`.
- The `npm audit` findings in the supplied output are separate from these compile errors. Do not use `npm audit fix --force` blindly because it can install breaking major versions; review `npm audit` output first.
